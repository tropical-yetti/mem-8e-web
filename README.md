# MEM-8E Web

Simulador educacional que mostra, por dentro, como funciona a memória do
computador: o endereço chega ao barramento de endereços, os decodificadores
escolhem a célula e o dado chega ao barramento de dados. Projeto irmão do
[CPU-8E Web](https://github.com/tropical-yetti/cpu-8e-web).
